# ExThrifts brand marks

A black-and-white vintage stamp. Every file here is generated from **one geometry** in
[`build-brand.py`](build-brand.py): a condensed bold capital alphabet drawn as polygons and
fixed-width strokes on a 100-unit cap height. No file uses `<text>` or a font, so each one
renders identically in any browser, PDF library or image tool. Colours are only `#000` and `#fff`.
Nothing makes a claim beyond the name and "Vintage · Thrift · Pakistan": no founding year,
no awards.

## Files

| File | What it is | Use it for |
|---|---|---|
| `stamp.svg` | Round stamp: EXTHRIFTS on the top arc, VINTAGE · THRIFT · PAKISTAN on the lower arc, stars at 9 and 3 o'clock, double ring rules, bold EX centre. Black on transparent. | Primary logo: hero, footer, about page, **parcel slip** (prints crisply at 25 mm wide on a laser printer). Minimum size about 160 px on screen or 25 mm in print. Below that the lower lettering fills in, so use the tag or monogram. |
| `stamp-white.svg` | The same stamp in white on transparent. | On black or photo backgrounds. |
| `stamp-distressed.svg` | The stamp with fixed ink-wear specks on the rim and a few hairline scratches, made with an SVG mask of 0/1 values only. | Decorative use only: social posts, packaging stickers, large hero art. **Not for the parcel slip or small sizes.** Some PDF libraries do not support SVG masks, so use `stamp.svg` there. |
| `tag.svg` | Horizontal woven-label lockup: double-ruled frame, solid block with EX cut out, then THRIFTS. viewBox 389.4 × 120 (about 3.25 : 1). | **Website header** and **parcel slip header**. Tested legible at 32 px tall (and still readable at 24 px). |
| `tag-white.svg` | The tag in white. The EX is cut through, so the background shows inside the letters. | Header on a black bar or dark mode. |
| `monogram.svg` | Solid disc with a ring rule, EX cut out (transparent). | Avatars, stickers, watermark, anything 48 px and up. |
| `monogram-white.svg` | The monogram in white. | On dark backgrounds. |
| `wordmark.svg` | EXTHRIFTS on its own, no frame and no tagline. viewBox 547.6 × 100. | Wherever a frame is too busy: OG image, email signature, footer line. |
| `favicon.svg` | Black disc with EX painted white. Fitted to the 16 px pixel grid (stems 2 px, E counters 1 px), so it stays sharp at 16 and 32 px. | `<link rel="icon" type="image/svg+xml">`. |
| `favicon-32.png` | 32 × 32 raster of the favicon. | Fallback `<link rel="icon" sizes="32x32">`. |
| `apple-touch-icon.png` | 180 × 180, full-bleed black with a white ring and EX. | `<link rel="apple-touch-icon">`. iOS rounds the corners itself. |
| `icon-192.png`, `icon-512.png` | Black disc mark with a white ring and EX on transparent. | Web app manifest icons, `purpose: "any"`. |
| `maskable-512.png` | Full-bleed black. The ring's outer edge is at 71% of the canvas, inside the 80% maskable safe circle. | Manifest icon, `purpose: "maskable"`. |
| `og-image.png` | 1200 × 630, white background, stamp on the left and wordmark on the right. | `og:image` / `twitter:image`. |
| `stamp-1200.png`, `tag-240h.png` | Black-on-transparent rasters of the stamp (1200 px) and the tag (240 px tall). | For any tool that cannot take SVG, such as a PDF renderer without SVG support. |
| `android/ic_launcher_foreground.png` | 432 × 432 adaptive-icon foreground: white ring and EX on transparent. The ring's outer edge is at 60.2% of the canvas, inside the 66 dp / 108 dp (61.1%) safe zone. | Android launcher icon. |
| `android/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher_foreground.png` | The foreground at 108, 162, 216, 324 and 432 px. | Copy to `res/mipmap-*/`. |
| `android/mipmap-*/ic_launcher.png`, `ic_launcher_round.png` | Legacy (pre-API 26) icons: the black disc mark at 48, 72, 96, 144 and 192 px. | Copy to `res/mipmap-*/` for older devices. |
| `android/ic_launcher_background.xml` | `ic_launcher_background` = **#000000**, the black background layer. | Copy to `res/values/`. Reference it as `@color/ic_launcher_background` in `mipmap-anydpi-v26/ic_launcher.xml`. |
| `png-src/` | The composed SVGs the PNGs are rasterised from, plus `manifest.json` (source, output, size, background for each PNG). | Generated by the build. Do not edit by hand. |
| `build-brand.py`, `export-png.mjs` | The generator and the rasteriser. | See below. |

### Suggested site wiring

The other session will do this wiring.

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon-32.png" sizes="32x32" type="image/png">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

Manifest icons: `icon-192.png` and `icon-512.png` (`any`), and `maskable-512.png` (`maskable`).
Give the header tag an explicit height (for example `height: 32px; width: auto`). Its
`aria-label`/`<title>` is "ExThrifts".

## Rebuild

Run from the repository root:

```bash
python brand/build-brand.py
```

```bash
node brand/export-png.mjs
```

The first command writes every SVG here and in `png-src/`, plus `png-src/manifest.json`. It
needs only the Python 3.12 standard library. The second renders every PNG in the manifest with
`sharp`, which resolves from the repository root's `node_modules` (it is already a root
dependency, so there is no separate install).

To change the look, edit the geometry in `build-brand.py`, for example `GLYPH()` for the letters,
`STAMP` for the ring radii and `TAG_H`/`tag()` for the label. Then run both commands again.
Every mark updates together.

### Visual check

```bash
node brand/export-png.mjs --preview <dir>
```

This writes inspection renders to a folder of your choice (default: the OS temp folder, never
the repository):

- each SVG large;
- the tag at 32 px and 24 px tall, enlarged without smoothing so you see the real pixels;
- the favicon and monogram at 16 px and 32 px, enlarged the same way;
- the stamp at 25 mm and 300 dpi (295 px), the parcel-slip size;
- the Android foreground on its black layer with the launcher's circle mask and the safe-zone
  circle drawn as a dashed line.

Look at them after any geometry change.
